# FLONGA — Stage 1: City Entrance

A browser-playable procedural 3D prototype built with Three.js. No local 3D assets are required.

## Run
Open `index.html` locally or upload the folder to GitHub and enable **Settings → Pages → Deploy from a branch → main / root**.

## Controls
- WASD / Arrow keys: move
- Shift: sprint
- E: interact with Clothing Store

## Stage 1 mission
1. Go to the Clothing Store
2. Buy 1 T-Shirt
3. Collect 5 Coins

The project is intentionally asset-light so GitHub Pages can host it easily; the concept image can be used as the visual blueprint for expanding the 50-stage game.
