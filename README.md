# FLONGA — Stage 2: Fashion Avenue

A browser-playable Three.js stage designed as the second level of the FLONGA Street Shopping Game.

## Mission
- Visit the Fashion Store
- Collect 8 coins
- Buy a Street Outfit
- Find the Shoe Store

## Controls
WASD / Arrow Keys = move
Shift = sprint
E = interact

## Run / GitHub Pages
Upload this folder to a GitHub repository and enable GitHub Pages. `index.html` is the entry point.

## Stage 2 additions
- Larger Fashion Avenue
- Five stores
- Visible storefront interiors
- Three selectable outfits
- 14 pedestrians
- Moving traffic
- Collectible coins
- Lighting and environmental props
- Mission progression and completion UI
